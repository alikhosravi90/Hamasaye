# همسایه‌های ما | Hamasaye

طرح مردمی و اقتصادی برای شناخت، سلامت و همزیستی مسئولانه انسان، حیوانات شهری و حیات‌وحش در باغستان غربی کرج.

**وضعیت:** طرح مفهومی و پایلوت پیشنهادی؛ هیچ قرارداد، مرکز امداد، گواهی سلامت یا داده سرشماری واقعی هنوز تأیید نشده است.

## چشم‌انداز
شناخت حیوانات فردی و گونه‌ها، روایت زنده مشاهدات، آموزش علمی، کاهش ترس و تعارض، مراقبت دامپزشکی، کنترل انسانی جمعیت و حفاظت از زیستگاه.

## محصولات
1. اطلس زنده گونه‌ها و حیوانات محله؛ 2. شبکه گزارش، امداد و ارجاع دامپزشکی؛ 3. مدرسه همزیستی و تصحیح باورها؛ 4. مدیریت قراردادها، تجهیزات و حامیان؛ 5. داشبورد سنجش اثر و اقتصاد.

## اصول
رفاه حیوان، سلامت انسان، حفظ محیط‌زیست (One Health)، صلاحیت حرفه‌ای، داده معتبر، محرمانگی مکان‌های حساس، شفافیت مالی، عدم آزار و استقلال تصمیم درمانی از اسپانسر.
